# 霜催落月 練習場（燕雲十六聲 五人試劍副本）

用 Three.js 做的 3D 機制練習場：你只控制自己，其他 4 人是照攻略行動的 NPC；做錯會立刻停下並用中文說明原因。
每個機制可以單選，也能跑單隻王全程或兩隻王全程；勾「自動模式」可以看 5 人全自動示範。

範圍大小、時間、小怪血量是推估值。

直接雙擊 `index.html` 就能開（需要網路載入字型；Three.js 已附在資料夾內）。

## 操作

| 按鍵 | 動作 |
|---|---|
| W A S D | 移動 |
| 空白 | 閃避（0.45 秒無敵，冷卻 1 秒） |
| F | 卸勢：白圈縮到腳下（頭上出現「卸」）時按，窗口約 0.55 秒，按太早要等冷卻 |
| Q | 技能：人形＝太極（把 6.5m 內的人偶丟到王腳下）、狼＝格擋、鷹＝揭露前方長方形 |
| E | 互動：在靈劍旁邊變身、狼靠近被困的隊友把他載起來 |
| 滑鼠拖曳 | 轉視角，同時是狼劍氣／鷹揭露的瞄準方向 |
| 滾輪 | 縮放 |
| Enter | 開始／重來 |

站在小怪旁邊（約 3.6m 內）會自動普攻，並順劈旁邊的小怪。手機有虛擬搖桿和動作按鈕。

## 隊伍與分工

- 1 坦（坦）、1 奶（奶）、3 輸出（輸1～輸3）。
- 熄燈時有 5 個燈位（離中心 10m），每人一個：坦＝北，順時針 輸1、輸2、輸3、奶。
- 狐火監牢：輸1 變狼去救（輸1 被點名時換 輸2）。
- 狐神舞：坦＋輸1 打一團、輸2＋輸3 打另一團，奶在中間。
- 狐神舞·極：輸3 變鷹揭露，其他人打。

## 機制

**王 A：桃靨劍姬**（金色舞台；分明亮／黑暗兩階段）

1. 長虹貫日（明亮）：黃條接黃圈點名，被點名的人遠離人群（爆炸 4.5m），兩輪。
2. 千花綻放（明亮）：點名全員，分散 3m。
3. 天外飛仙：飛到空中連續紅圈點名 3 人，卸勢；別站在別人的紅圈裡。
4. 流光劍舞：點名 1 人連續 4 段高額傷害，每段都要卸勢；其他人離 3m 以上。
5. 黑暗階段：場地變黑，光亮區域有三種型態（中圈 4 個燈／中央一大圈／中圈 3 個燈）；
   之後穿插長虹貫日、天外飛仙、千花綻放，黑暗中都是秒殺。長虹貫日時和被點名的人同一個燈要換到最近的燈。
6. 百戲人偶：6 隻（或 3 隻）人偶 30 秒後各暗殺全團一次，場地由外向內變暗；坦把王拉在中央，其他人用太極把負責的人偶丟回中央集合擊殺。
7. 天女散花：黑暗中多次紅圈點名（4 次），及時站進光亮區域卸勢；失敗爆炸會波及碰到的隊友。
8. 百戲人偶·巨：四個角落各一隻，腳下燈光不斷縮小；集火其中兩隻（「集火 1／2」），沒打死的腳下仍留很小的燈光。
   接著全員點名：保住的兩個燈各站 2 人，第 5 人站小燈光。

**王 B：耶律阿不里**（夜晚花海）

1. 狼靈召喚：全隊集火不會動的狼靈，坦把王拉過去；死後留下狼靈劍。
2. 鷹靈召喚：鷹靈對人射小紅圈，每次都要卸勢，耗光氣竭值後墜落留下鷹靈劍。
3. 狼神附身＋狼神鼓：全員到狼靈劍按 E 變狼，每擊鼓按 Q 卸勢王的紅圈傷害，反擊劍氣要對準王（不會自動瞄準），3 擊破盾；期間腳下的金光不必躲。
4. 狐火監牢：被點名的人先離開人群與狼靈劍；救援者變狼載他出監牢（10 秒內）。
5. 狐神舞：王無敵，兩組各打一團狐火。
6. 狐神舞·極：4 團狐火 2 秒後隱身；鷹從外側面向狐火按 Q 揭露（別對著隊友），其他人揭露後去打。
7. 狐火爆炎：連續點名 3 人，把狐火帶到場邊（11m 以外），藍圈鎖定後走出來或閃避；火焰會留在地上。

## 自行推斷的部分

攻略只說明招式效果，下列細節是自行決定的，和實際副本可能不同：各招的時間與範圍大小、
黑暗階段裡穿插哪些點名與順序、燈內兩人的站法、狐火監牢會把旁邊的人一起關、每個機制開始時大家恢復人形、
狐火爆炎要帶到 11m 以外。卸勢失敗一律判失敗（實戰是眩暈或爆炸，練習時要求每次都卸到）。

## 專案結構

```
index.html            HUD／設定面板骨架
css/style.css
three.min.js          Three.js r152（本機優先，失敗再試 CDN）
js/boot.js            載入 Three.js，再依 APP_FILES 順序載入下列檔案
js/core/constants.js  職能、燈位、幾何小工具
js/core/scene.js      渲染器、相機、兩種地板、熄燈黑幕、兩隻王
js/core/visuals.js    地面範圍、標籤、血條、特效
js/core/members.js    5 名隊員（人形／狼形／鷹形）
js/core/engine.js     設定、時間軸引擎、成功／失敗
js/core/combat.js     小怪普攻、卸勢、閃避、燈光、靈劍變身、太極／格擋／揭露
js/mechanics/*.js     共用工具、桃靨劍姬、耶律阿不里
js/steps.js           機制順序（也自動產生「練習範圍」選單）
js/input.js, js/main.js
tests/runner.js       自動測試（不屬於遊戲本體）
```

## 自動測試

在瀏覽器主控台載入 `tests/runner.js` 後：

```js
__matrix(3); // 全部機制 × 5 職能 × 4 組變體 × 3 次，自動模式應全部通過
__runSync(STEPS.map((s) => s.id), 'D1', { targetVar: 'me' }, false); // 玩家不動，應該要失敗
```
